# Meu Dinheiro Controlado

Um aplicativo para gerenciar suas finanças pessoais de forma simples e eficiente.

## 📋 Funcionalidades

- ✅ Registro de receitas e despesas
- ✅ Categorização de transações
- ✅ Relatórios e gráficos financeiros
- ✅ Orçamento personalizado
- ✅ Histórico de transações

## 🚀 Como Começar

### Pré-requisitos
- Node.js (v14+)
- npm ou yarn

### Instalação

```bash
git clone https://github.com/seu-usuario/meudinheirocontrolado.git
cd meudinheirocontrolado
npm install
```

### Uso

```bash
npm start
```
